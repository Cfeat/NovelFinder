# 拾页 · 小说推荐工具

用户搜索或手动添加喜欢的小说，系统归纳共同标签并推荐其他作品。每条推荐都关联一本喜好作品并解释共同元素。推荐会排除已经添加的小说。

## 当前版本

- 首批抓取 757 条平台公开书目（2026-10-07），与 16 本人工整理作品合并后为 771 本；实际数量以界面为准。20 个阅读元素。
- 从已收录书目中搜索书名、作者，按平台筛选；支持按需调用晋江公开书名搜索，或者手动添加作品并选择 1–6 个标签。
- 喜好保存在 D1 数据库，以平台提供的登录用户 ID 隔离；刷新、再次登录后可以继续使用。
- 按标签相似性、偏好权重及同作者加分排序。少见的共同标签权重更高。
- 平台书目取自公开网页：书名、作者、分类、简介摘录、平台作品 ID、原站链接及采集时间。推荐标签由公开分类、原站标签映射；人工整理作品保留人工标签。不会推测未提供的分类和风格，未分类作品可能只能给出探索推荐。未使用大模型，契合程度不代表作品评分。界面封面为本站排版。
- D1 缓存增量合并；登录后访问页面时，超过 24 小时自动检查更新。手动检查至少间隔 1 小时，并使用数据库锁防止并发重复抓取；每个平台串行、每次请求 9 秒超时。平台失败或验证时保留旧书目并记录失败。没有无人访问时的后台定时任务。
- 数据库异常不会伪装为成功保存；输入保留并显示可重试错误。

## 本地运行

需要 Node.js 22.13+。在本目录运行：

```powershell
npm run install:ci
npm run db:generate
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_*.sql
npm run dev
```

迁移命令需填写实际生成的 SQL 文件名，按顺序执行且不重复已应用的迁移。本地预览地址以终端输出为准。访问 `/signin-with-chatgpt?return_to=/` 可使用开发环境的模拟用户；模拟登录不会包含在生产构建中。

```powershell
node --experimental-strip-types --test tests/catalog.test.mjs tests/recommendations.test.mjs
node node_modules/typescript/bin/tsc --noEmit
```

在启动构建后的本地 Worker（`npm start`）之后，用 PowerShell 7 运行 `./tests/api.integration.ps1`。通过 `NOVEL_TEST_ORIGIN` 指定终端打印的本地地址（默认 `http://127.0.0.1:8787`）。该测试仅允许 localhost，使用随机测试用户并在结束时清理自己的记录，验证鉴权、保存、用户隔离、输入校验和移除。开发预览的登录模拟会主动剥离伪造身份头，因此该集成测试应针对构建后的本地 Worker 运行。

## 结构

- `components/novel-finder.tsx`：界面、搜索和书单交互。
- `lib/novels.ts`：人工起步书库、偏好画像、推荐排序与理由（接收动态书库）。
- `lib/catalog/`：平台 HTML/JSON 解析、分类映射、去重、抓取与快照读取。
- `data/public-catalog.json`：真实抓取的初始公开书目与来源状态，数据库为空时也可使用。
- `db/catalog.ts`：D1 增量缓存、同步锁和来源状态。
- `app/api/catalog/`：读取、检查更新和晋江按需搜索。
- `lib/favorite-input.ts`：输入验证与书名去重。
- `app/api/favorites/route.ts`：读取、添加、移除喜好；服务端鉴权。
- `db/schema.ts` 与 `drizzle/`：数据库定义与版本化迁移。

## 覆盖范围与接入限制

| 平台 | 本批书目 | 获取范围 | 当前限制 |
| --- | ---: | --- | --- |
| 番茄小说 | 47 | 首页公开推荐及更新列表 | 未接入整个书库 |
| 晋江文学城 | 500 | 作品库前 5 页；按需公开书名搜索 | 搜索结果未提供简介时明确标注；非全量 |
| 纵横中文网 | 180 | 首页与 5 个分类页 | 未接入整个书库 |
| 17K 小说网 | 30 | 作品库；配置前 5 页 | 当前仅第 1 页成功，后续访问验证 |
| 起点中文网 | 0 | 尝试公开书库 | 返回访问验证，未成功入库 |
| 七猫中文网 | 0 | 尝试公开书库 | 访问验证或网络失败，未成功入库 |

这些是公开网页适配器，未使用平台合作 API，未绕过验证。已验证的来源计入平台数量；人工起点书目附有原站链接也不会算作起点数据接入。公开网页不能保证全平台、全量完整，页面变化、下架及网络限制都会影响覆盖。已缓存的书目保留采集时间；增量刷新不证明作品仍在原站上架，使用原站链接核查。

跨来源按规范化书名和作者合并，已有起步作品保留旧 ID 以兼容喜好书单。原有喜好书单按书名防止重复添加。服务仅推荐和介绍书目，不获取小说正文、付费章节或阅读授权。

可重新获取初始快照：

```powershell
node --experimental-strip-types scripts/sync-public-catalog.mjs
```

脚本只在至少一个来源成功时写入快照。运行后检查来源状态、解析测试和类型检查，再构建部署。线上刷新使用 D1 缓存，平台失败不会覆盖或删除已有书目。

阅文提供合作方全量 ID 与书籍信息接口，需要注册配置、appKey、签名密钥及 IP 白名单：[开发前必读](https://open.yuewen.com/docs/1001.html)。如需完整大平台书库，需要取得相应接入资格或授权数据供应。
